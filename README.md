# Phantom invite

Convite interativo curto, com estetica inspirada em teatro, baile de mascaras e *O Fantasma da Opera*.

## Rodar localmente

```sh
npm install
npm run dev
```

A faixa `Body - Mother Mother` e reproduzida localmente quando o convite abre. Alguns navegadores exigem o primeiro toque para liberar audio com som.

## Notificacao de aceite

Ao clicar em "Sim, eu iria", o site envia uma notificacao para `samuelmedeiros2025@gmail.com` via FormSubmit. O primeiro envio exige que o destinatario confirme a ativacao recebida por e-mail.
